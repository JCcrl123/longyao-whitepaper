# 珑曜装修白皮书

广州地铁地产 · 珑曜上城（一期）家装白皮书。

以 2 栋 04 户型（建面 89.5㎡、4 房 2 厅 2 卫、西南向阳台）为原型编写，内容对一期全部户型通用。

## 内容范围

- 执行摘要与花费结构
- 46 项材料全表 · 逐条批判性审计（批判点 / 补全规格 / 客观建议）
- 柜体材料全维度（板材形成工艺、胶水用量、环保等级、国产 vs 进口）
- 封窗材料全维度（型材 / 腔体 / 隔热条 / 胶条 / 玻璃 / 五金 / 纱窗）
- 地砖材料全维度
- 家私选购（真皮甄别、餐桌材料、餐厅形状匹配）
- 家电选购（挂机 vs 柜机、面积对应匹数、变频 vs 定频、冰箱 / 洗烘 / 洗碗机）
- 床品与窗帘选购（成品床材料、飘窗储物异形床、七空间窗帘落点）
- 材料行情与计价口径核验
- 9 阶段施工时间轴
- 避坑清单
